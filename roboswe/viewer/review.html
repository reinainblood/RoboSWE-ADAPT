THE BENCHMARK, AS IT STANDS

Can a coding agent learn to operate a robot?

RoboSWE-ADAPT studies agents that write Python movement libraries, act through bounded native robot controls, inspect visual and proprioceptive feedback, and retain experience across repeated attempts.

MuJoCo and RoboCasa supply the simulated kitchens. RoboSWE supplies the coding harness, isolated execution, evidence capture, and learning protocol. This is a research preview, not a calibrated leaderboard.

  • Fresh physical scene for each retained-learning attempt.
  • Official predicates and recorded sustained success.
  • Separate replay verification and optional multi-view visual audits.
  • Original observations, actions, failures, and available reasoning retained.
Historical cohorts used different attempt counts, backends, and context policies. Compare matched protocols only. Missing attempts and infrastructure failures remain visible; a visual audit never silently changes a mechanical score.
